# 公开版测试说明

运行：`python -m unittest discover -s tests/characterization -v`。先安装 `requirements.txt` 并构建前端，HTTP 集成测试需要 `dashboard.html`。

当前测试集共 58 项：

- 独立执行器、持久化、循环、周期调度与状态转换测试。
- 数据库连接、网页来源安全分类、报告证据锁定与章节校验。
- 离线 HTTP 保护、临时虚构工作区、模拟采样写入、凭据保存拒绝、私有文件禁止访问、HTML 不缓存。
- 初始模拟报告生成、冻结 PDF 格式与 SHA-256 校验、模拟门户登录及写入限制。

每项数据库测试使用临时文件；HTTP 集成测试只复制必要源码和虚构种子，生成新的临时数据库。测试不会读取项目运行库作为夹具，更不会读取正式客户库。

旧内部完整测试曾依赖业务数据库及部署目录。此公开仓库没有这些数据，也不携带那套未经独立适配的测试；公开版覆盖自己的离线体验范围。保留的执行器测试使用假的时间和回调，不能代表已验证真实平台 API 可用性。
