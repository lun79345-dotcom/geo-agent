# 从回答到行动

GEO Agent 的设计重点是保存判断过程：每条结论能回到提问、回答和证据，建议可以进入任务，任务可以关联复测，交付报告保存确定版本。

品牌出现率与推荐率分开，因为「回答提到品牌」与「把品牌列为可考虑的候选」是不同现象。事实风险需要人工复核；提及更多并不意味着内容更准确。

周期比较要求保持题集、平台配置与样本范围一致。换题或换模型后的百分比不能直接解释为优化效果。公开版的虚构样本没有真实周期可比性，因此不会显示成正式趋势。

报告采用草稿、审核、版本与冻结 PDF 流程。PDF 下载校验保存时的摘要，客户门户只读指定客户的已发布版本。

React 与 TypeScript 承担工作台交互；Python 与 SQLite 承担可追踪记录和状态转换。公开版继续保留产品的主体结构，同时替换客户资料、Logo、导入夹具与启动流程。

公开版的网络阻断是强制行为，没有通过配置开启付费 API 的开关。网页抓取和模型调用也因此不可用。这让作品访客可以在没有任何账户或额度的情况下理解主要数据流。
