# GEO Agent｜AI 品牌可见度监测与优化工作台

## 作品卡片

GEO Agent 把 AI 回答中的品牌提及、推荐和事实风险整理成可追踪的工作流。从品牌事实库与提问题集出发，连接样本、分析复核、内容优化任务、同题复测和报告交付。

公开版提供虚构品牌和离线模拟体验，不需要 API Key。它展示的是产品流程与工程实现；模拟指标不代表真实平台表现，API 近似采样也不等同于客户端排名。

技术：React、TypeScript、Vite、Python、SQLite、ReportLab。

GitHub：[lun79345-dotcom/geo-agent](https://github.com/lun79345-dotcom/geo-agent)

## 作品详情页正文

我希望做一个能把观察结果接到下一步行动的工作台。看到 AI 回答里有没有品牌只是起点：还需要知道回答是否准确、证据从哪里来、缺口该由什么内容补上，以及之后该怎样验证。

GEO Agent 围绕这条链路组织界面：先建品牌事实库，再管理提问题集，保存回答并复核判断，最后把建议变成任务和版本化报告。品牌提及与推荐分开显示；优化任务经过质量检查与人工批准，交付状态与效果确认也分开记录。

实现上，React 和 TypeScript 负责工作台交互，Python API 和 SQLite 保存记录、关联与状态。报告经过人工审核后保存版本和冻结 PDF，客户门户只展示已发布内容。

公开展示时，我把客户资料、内部品牌资产和运行配置替换成虚构种子，加入强制离线保护与独立测试。访客可以本地运行，无需任何模型账户或预算。

当前版本仍有边界：后端模块较大，平台适配器保留在源码中，但公开版不执行网络采样和模型调用，也不会把模拟结果显示为正式周期趋势。我会继续围绕模块拆分、演示可读性和状态验证改进它。
